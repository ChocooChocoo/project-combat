# Objective: Improve UI/UX and Fix Inconsistencies for the Combat Sports Platform

## Role

Frontend / UI-UX engineer

## Goal

Improve the platform's overall UI/UX and fix the inconsistencies identified in Phase 2 and Phase 3.

- Add complete form validation.
- Replace page loaders and spinners with skeleton loaders.
- Fix the transparent modals and dialogs.
- Add a navbar with a notifications menu.

## Context

- The work is based on the Phase 2 and Phase 3 findings.
- For overall project context, read [`CLAUDE.md`](http://CLAUDE.md) and `docs/ANALYSIS - COMBAT SPORTS PLATFORM`.
- Notifications currently sit in the sidebar.

## Tasks

### UI/UX consistency

- Review Phase 2 and Phase 3, then fix the UI/UX inconsistencies they identify.

### Form validation

- Add validation to every field in every form.

### Loading states

- Replace all page loaders and spinners with skeleton loaders.

### Modals and dialogs

- Fix the modals and dialogs that currently show a transparent background.

### Navbar and notifications

- Add a navbar to the pages.
- Remove notifications from the sidebar.
- Add a notification icon on the right side of the navbar.
- Clicking the icon opens a dropdown menu that shows the notification content.
