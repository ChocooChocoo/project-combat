# Objective: Design and Implement Data-Driven User Dashboards

## Role

Act as a UI/UX designer and dashboard design specialist, leveraging installed Claude skills related to design, UI/UX, anti-slop principles, and other relevant capabilities.

## Goal

Design and implement visually engaging, well-structured dashboards for every user, separate from the existing home pages. Each dashboard must display actual, real data through meaningful visualizations and information widgets.

Ensure that every dashboard follows a clear information hierarchy, typography hierarchy, visual hierarchy, and data hierarchy to improve readability, usability, and overall user experience.

## Success Criteria

- Every user has a dedicated dashboard distinct from their home page.
- Dashboards display real, accurate data rather than placeholder or fabricated information.
- Dashboards incorporate appropriate visualization components, including:
  - KPI cards
  - Charts and graphs
  - Heatmaps
  - Other relevant data and information widgets
- Dashboard layouts maintain consistent visual, textual, and data hierarchies.
- Information is presented clearly, logically, and intuitively.
- Designs follow established UI/UX principles and avoid generic, cluttered, or low-quality AI-generated aesthetics.

## Constraints

- Keep dashboards separate from existing home pages.
- Use actual data for all displayed metrics and visualizations.
- Apply relevant installed Claude skills for design, UI/UX, anti-slop design practices, and other applicable areas.
- Prioritize clarity, usability, meaningful data visualization, and effective information hierarchy.

## Context

- Users currently do not have dedicated dashboards.
- Existing home pages are separate from the proposed dashboards.
- Installed Claude skills are available to support the design and implementation process.

## Tasks

1. Review the available installed Claude skills relevant to dashboard design, UI/UX, visual hierarchy, and anti-slop practices.
2. Design dedicated dashboards for every user.
3. Identify and organize the actual data to be displayed in each dashboard.
4. Incorporate suitable KPI cards, charts, heatmaps, and other relevant information widgets.
5. Establish clear information, typography, visual, and data hierarchies.
6. Implement the dashboards while maintaining separation from the existing home pages.
7. Ensure the final dashboards are visually cohesive, readable, intuitive, and populated with real data.
