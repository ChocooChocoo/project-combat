# Objective: Add a Realistic Seeder for Data Introduced or Changed by Plans P09, P10, and P11

## Goal

Create a new seeder that populates realistic dummy data for the new or modified data introduced by the three implementation plans (already technically implemented). The data should match the realism of the existing seeder and replace the ad-hoc test data currently used during testing.

- Retain the full range of statuses (e.g., pending, approved, cancelled, rejected, and others) in the seeded records.
- Include the provided AI-generated sample document image in the seeded data.

## Success Criteria

- A new seeder exists that covers all new or changed data from the three plans.
- Seeded data is realistic and consistent with the style of the current seeder, not test-looking placeholder data.
- Every status value relevant to each seeded entity is represented.
- Sample documents use the provided AI-generated image.
- Other images and files are sourced from the root-level `assets/images` and `assets/documents` directories.

## Tasks
