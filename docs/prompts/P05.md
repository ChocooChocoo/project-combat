# Objective: Add attendance, payroll, permission-based sidebar, and subscription plan changes to the gym system roadmap



## Goal

Add the changes, additions and revisions below to the gym management system's roadmap. Where an item is new or changed functionality, also update the analysis folder to match.



## Success Criteria

- Every item below appears on the roadmap.

- The analysis folder reflects every functional change.

- Staff can check in and check out against schedules set by gym owners, with a grace period of at least 10 minutes for late clock-ins.

- Payroll includes each staff member's attendance: present, late and absent.

- Users only see the sidebar modules their role allows.

- The admin can create and edit subscription plans, including what each plan includes and which features each plan can and cannot use.

- After the free trial ends, gym owners who have not subscribed lose access to some or all owner-side features.



## Constraints

- The attendance grace period must be at least 10 minutes.

- Gym owners must subscribe once the free trial ends.



## Context

- The system has gym owners, staff, an HR/operations side that handles payroll, and an admin side for the platform.

- Roles and permissions already exist. The input mentions a current issue or ongoing work with them.

- Gym owners can register their gyms for free on a trial, for example one month of platform use.



## Tasks

### Staff / Employees

- Build attendance management so every staff member can check in and check out.

- Tie attendance to the schedules gym owners set.

- Apply a grace period of at least 10 minutes so late staff can still clock in.



### HR / Operations

- Bring attendance records (present, late, absent) into payroll management.



### Technical



- Hide sidebar modules from users whose role does not grant access to them.



### Admin

- Add a subscription plan module where the admin can create plans (for example Free, Pro, Ultra).

- Let the admin edit each plan's inclusions and choose which features each plan can and cannot access.

- Suggest names for the plans.

- Put new gym registrations on a free trial, and limit owner-side features when the trial ends without a subscription.



### Documentation

- Add every item to the roadmap.

- Update the analysis folder for each functional change.



## Open Questions

- How should late arrivals and absences affect pay? For example, are there deductions, and how much?

- Is the grace period a fixed 10 minutes, or can each gym owner set it (with 10 minutes as the minimum)?

- What happens when a staff member clocks in after the grace period ends?

- What is the current issue with roles and permissions ("working hour back right now")?

- When a trial ends without a subscription, are all owner-side features blocked, or only some? If only some, which ones?

- Is the trial length fixed at one month, or can the admin set it?

- Is "Free" a permanent plan tier, or does it mean the trial?

- Who runs payroll: HR, operations staff, or the gym owner?
