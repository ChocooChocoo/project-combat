# Objective: Design and Build a Complete Application Landing Page

## Role

Act as a development and UI/UX design team, using specialized AI models and parallel sub-agents for exploration and design.

## Goal

Build a comprehensive landing page that showcases everything the application offers, accurately represents its features and capabilities, and displays real data retrieved from the application's database.

## Success Criteria

- A complete, visually polished landing page showcasing the application's features and capabilities.
- Real database-driven content instead of fabricated or placeholder data.
- Relevant online images that realistically represent the application.
- A modern, professional, cohesive design that avoids generic AI-generated aesthetics ("AI slop").

## Constraints

- Use only the latest DeepSeek V4.1 Flash with maximum reasoning effort for exploration. Do not use any other DeepSeek variants.
- Use GPT-6 Astra with Medium reasoning effort for the design stage.
- Leverage relevant installed design skills available in OpenCode or Claude Code.
- Prioritize realistic visuals, consistent design, and authentic application content.

## Context

- The landing page must represent the existing application's actual functionality.
- The application's database serves as the source of truth for displayed data.
- Installed OpenCode or Claude Code design skills are available for improving design quality.

## Tasks

### Phase 1: Exploration (DeepSeek V4.1 Flash, Max Effort)

- Explore the existing application, its features, architecture, and database.
- Use multiple parallel sub-agents to investigate different aspects of the system.
- Identify the application's key capabilities and available database content for the landing page.

### Phase 2: Design (GPT-6 Astra, Medium Effort)

- Design the landing page based on the exploration findings.
- Apply relevant installed OpenCode or Claude Code design skills.
- Incorporate appropriate online images for a realistic visual showcase.
- Ensure the design is professional, cohesive, and free from generic AI-generated patterns.

### Phase 3: Landing Page Implementation

- Build the landing page according to the finalized design.
- Showcase the application's actual features and capabilities.
- Integrate real database data into the landing page.
- Ensure the displayed information accurately reflects the existing application.
