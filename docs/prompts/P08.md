# Objective: Limit the System's Location Scope to Cavite Province

## Goal

Change the system's geographic scope from the entire Philippines to Cavite only, with dependent location selection: the province is fixed to Cavite, choosing a municipality shows only its barangays, and the zip code fills in automatically.

## Success Criteria

- The province is set to Cavite automatically and is not selectable.
- All Cavite municipalities are available for selection.
- Selecting a municipality (e.g., Dasmariñas) lists only the barangays in that municipality.
- The correct zip code appears automatically once the location is selected.

## Constraints

- Only Cavite locations are in scope. Locations outside Cavite are excluded.

## Context

- The system currently covers locations across the whole Philippines.

## Tasks

1. Restrict the location scope from nationwide to Cavite only.
2. Fix the province field to Cavite.
3. Load all Cavite municipalities and their barangays.
4. Make the barangay list depend on the selected municipality.
5. Fill in the zip code automatically based on the selected location.

## Open Questions

- Should "municipality" also include Cavite's component cities (e.g., Dasmariñas, Bacoor, Imus)?
- Is the zip code tied to the municipality or to each barangay?
- What data source should be used for Cavite's barangays and zip codes?
- Should existing non-Cavite location data be deleted, or only hidden from selection?
- How should existing records that use non-Cavite addresses be handled?
