# Objective: Redesign Authentication Pages and Clarify User Roles

## Goal

Redesign the `/sign-in` and `/sign-up` pages to improve visual hierarchy, usability, and overall UI/UX. Establish a clearer registration process that allows users to choose between two account types: **Gym Member** and **Gym Owner**.

## Success Criteria

- Both authentication pages have improved visual hierarchy and a more intuitive user experience.
- The sign-up page clearly distinguishes between Gym Member and Gym Owner registration.
- Each account type has clearly defined roles, permissions, and access restrictions.
- Users are not confused about whether they can simultaneously act as Gym Members and Gym Owners.

## Context

The current registration process is too general and does not clearly distinguish between Gym Members and Gym Owners.

There is also ambiguity in how account roles work after authentication. For example, if a user registers as a Gym Owner and their application is approved, it is unclear whether they can still access the platform as a Gym Member.

The intended distinction is that regular Gym Members or clients should only be able to browse registered and approved gyms, without access to Gym Owner applications.

## Tasks

### 1. Authentication UI/UX Redesign

- Redesign `/sign-in` and `/sign-up` with better visual hierarchy and usability.
- Introduce a clear account-type selection during registration.
- Ensure users understand the difference between registering as a Gym Member and a Gym Owner.

### 2. User Roles and Permissions

- Review how the existing system assigns and manages account roles.
- Clarify the permissions and accessible features for Gym Members and Gym Owners.
- Ensure regular Gym Members can view registered and approved gyms but cannot submit Gym Owner applications.
- Examine how Gym Owner application approval affects the user's role and access.

### 3. Authentication and Role Consistency

- Evaluate whether the existing authentication and role-management logic aligns with the intended registration flow.
- Identify and resolve inconsistencies between account registration, Gym Owner approval, and authenticated user permissions.

## Open Questions

- Should Gym Member and Gym Owner accounts be mutually exclusive?
- If a Gym Owner's application is approved, should that user retain any Gym Member capabilities?
- How should the system handle existing accounts that currently have access to both roles?
